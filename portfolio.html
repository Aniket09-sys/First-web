About

I spend most of my time in a terminal — usually one running on hardware it wasn't quite designed for. I've built an AI agent from scratch on the Anthropic SDK inside Termux on Android, wired up background execution with tmux, and worked around every RAM and battery constraint that came with it.

On the web side, I build clean, fast front ends and the backends behind them — from a minimal portfolio site to an Express API handling contact forms with proper validation and rate limiting. I care about things working reliably, not just looking finished.

  • Languages Python, JavaScript
  • Runtime Node.js, Termux
  • Backend Express, Nodemailer
  • AI tooling Anthropic SDK
  • Hosting Netlify, Vercel, Railway
